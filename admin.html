Что сейчас настроено

    Токен показывается замаскированным: целиком его можно увидеть только у @BotFather.

    Настройки приёма заявок

    Эти поля нужны панели бота (bot.html). Сайт отправляет заявки сам, напрямую из браузера, поэтому его токен и chat_id лежат открытым текстом в файле tgdirect.js в репозитории. Поменяли бота или модератора — правьте начало этого файла и загружайте на GitHub.

    Публикация галереи в GitHub

    Нужно только для кнопки «Опубликовать» в галерее шаблонов. Токен хранится зашифрованным вместе с остальными настройками и даёт доступ только к этому репозиторию.

    Галерея шаблонов

    Шаблон — это фото примера плюс настройки заказа: материал, дизайн, цвет, форма, размер и тираж. Клиент на сайте нажимает на карточку, и конструктор сразу считает цену по этим настройкам.

    Шаблоны

      Пока ни одного шаблона. До публикации галереи на сайте нет.

      Публикация на сайте

      Сайт статический, поэтому шаблоны живут в репозитории: фото — в templates/img, список — в templates/catalog.js. Опубликованные шаблоны появляются на сайте через 1–2 минуты (GitHub Pages).

      Архив вручную

      1. Нажмите «Скачать архив для GitHub» — внутри папка templates с фото и каталогом.
      2. Откройте репозиторий на github.com → Add file → Upload files.
      3. Перетащите папку templates из архива (с заменой) и нажмите Commit changes.
      4. Через 1–2 минуты галерея обновится на сайте.

      Смена пароля

      Пароль нужен и для панели бота: без входа в админку панель заявки не принимает.

      Как это устроено

      Пароль и настройки живут только в этом браузере: в файлах сайта ни пароля, ни токена нет, поэтому их нельзя подсмотреть на GitHub или через исходный код страницы. Токен зашифрован паролем (AES-GCM), ключ выводится из пароля (PBKDF2-SHA256, 150 000 итераций).

      Что важно знать: если кто-то получил ваш токен бота, пароль от админки его не остановит — токен в этом случае нужно отозвать у @BotFather. Пароль защищает доступ к настройкам на устройстве и лежащий в браузере токен.
