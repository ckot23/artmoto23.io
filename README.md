# КОНТУР — сайт с расчётом и заявкой в Telegram

<p align="left"><img src="assets/logo-full.svg" alt="Контур — виниловая плёнка · наклейки на заказ" width="420"></p>

Статический сайт: описание плёнки, калькулятор стоимости по площади, корзина
для нескольких наклеек в одном заказе и заявка, которая приходит модератору в
Telegram и записывается в Google-таблицу. Сборка не нужна —
достаточно загрузить файлы на хостинг (GitHub Pages подходит).

## Плёнка и цены

Три фактуры, всё остальное снято с продажи:

| Плёнка | Цена за см² |
| --- | ---: |
| Матовая | 3 ₽ |
| Глянцевая | 4 ₽ |
| Металлик | 6 ₽ |

**Минимальный заказ — 500 ₽ на всю заявку.** Если сумма всех наклеек в корзине
выходит дешевле, считаем от 500 ₽; в корзине это показано отдельной строкой с
суммой доплаты. Две наклейки по 300 ₽ — это 600 ₽, минимум их не касается.

## Как считается цена

Формула одна на весь проект — `Pricing.quote()` в [pricing.js](pricing.js):

**ширина × высота × ставка плёнки × множители дизайна и цвета → округление до 5 ₽ →
скидка за тираж → подготовка макета** — по каждой позиции отдельно; затем сумма
позиций → **минимум 500 ₽** на всю корзину (`Pricing.quoteCart()`).

Её зовут и калькулятор на сайте, и панель бота, и проверка заявки. Поэтому сумма
на экране клиента и сумма в сообщении модератору не могут разойтись — есть
проверка на это в `npm test`.

Скидка за тираж считается внутри позиции, по её тиражу. Скидки: от 5 шт — −10%, от 10 — −18%, от 25 — −25%, от 50 — −32%, от 100 — −40%.

## Корзина: несколько наклеек в одном заказе

Клиент собирает заказ так:

1. В блоке **«Параметры наклейки»** выбирает плёнку, размер, тираж, дизайн, цвет,
   форму и эскиз — цена этой наклейки видна сразу.
2. Нажимает **«Подтвердить и добавить в корзину»** — наклейка ложится в корзину.
3. Меняет параметры (другой размер, другая плёнка, другой тираж) и добавляет
   следующую. Одинаковая наклейка не плодит строку — у неё растёт тираж.
4. В **корзине** у каждой позиции можно поменять тираж (− / +) или удалить её.
   Скидка за тираж и итог пересчитываются сами.
5. Заполняет имя и контакт и нажимает **«Отправить заявку»** — кнопка внутри корзины
   и неактивна, пока корзина пуста.

Корзина запоминается в браузере (localStorage): после перезагрузки страницы
позиции на месте. В одной заявке — до 20 позиций. Логика корзины — в
[cart.js](cart.js), расчёт и проверка — в [pricing.js](pricing.js).

## Заявка: Telegram и Google-таблица одновременно

Поток такой:

```
посетитель → «Отправить заявку» в корзине ─┬→ api.telegram.org/bot<ТОКЕН>/sendMessage → модератор
                                            └→ веб-приложение Google Apps Script → строки в таблице
```

Клиент указывает имя и контакт (телефон, Telegram или e-mail). Отдельный сервер не
нужен: сайт может лежать где угодно.

- **Telegram** — одно сообщение со всеми позициями, контактами и итогом (если не
  влезает в лимит Telegram в 4096 символов, делится на несколько по границам позиций).
- **Таблица** — по строке на каждую наклейку, у всех строк одного заказа общий номер.
  Итог заказа записан в первой строке, чтобы по колонке можно было считать суммы.
  Колонка «Статус» заполняется значением «Новая» — дальше её ведёт менеджер.

Заявка считается принятой, если дошла хотя бы в одно место. Если Telegram принял,
а таблица нет — менеджеру в чат прилетает отдельное предупреждение с номером заказа,
чтобы внести его вручную. Если не прошло никуда — клиент видит ошибку и запасной
путь: кнопки «Скопировать заявку» и «Переслать в Telegram» (корзина при этом остаётся).

## Заявки в Google-таблицу

Таблица подключается один раз, это занимает пять минут. Пока адрес не вписан,
заявки уходят только в Telegram.

1. Создайте Google-таблицу (лист называть не обязательно: скрипт сам создаст лист
   «Заявки» и шапку).
2. В таблице: **Расширения → Apps Script**. Удалите содержимое и вставьте код из
   [google-apps-script/Code.gs](google-apps-script/Code.gs). Сохраните.
3. **Начать развёртывание → Новое развёртывание → тип «Веб-приложение»**:
   - «Выполнять от имени» — **Я** (ваш аккаунт);
   - «У кого есть доступ» — **Все**.
   Нажмите «Развернуть» и разрешите доступ к таблице (Google предупредит, что
   приложение не проверено — это ваш собственный скрипт, нажмите «Дополнительно →
   Перейти»).
4. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и вставьте в
   `SHEET_URL` в начале [tgdirect.js](tgdirect.js):

   ```js
   var SHEET_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
5. Проверьте: откройте этот адрес в браузере — должен ответить `{"ok":true,...}`.
   Отправьте тестовую заявку с сайта — в таблице появятся строки.

Если вы меняете код скрипта, нужно **заново** сделать развёртывание
(«Управление развёртываниями → Изменить → Новая версия»), иначе работает старая версия.

Что учтено в скрипте:

- повторная отправка одного и того же номера заявки игнорируется — дублей не будет
  (сайт может повторить запрос, если браузер не дал прочитать ответ);
- значения, начинающиеся с `=`, `+`, `-`, `@`, записываются как текст — клиент не
  сможет вписать в комментарий формулу;
- две заявки одновременно не перепутают строки (блокировка).

⚠️ Адрес веб-приложения виден в исходном коде сайта, как и токен бота: любой, кто его
узнал, может дописать строки в таблицу. Сама таблица при этом закрыта — доступ к ней
у скрипта, а не у посетителей. Если в таблицу начнут писать лишнее — создайте новое
развёртывание (новый адрес) и замените `SHEET_URL`.

### Токен лежит в файлах

⚠️ Токен бота записан открытым текстом в начало [tgdirect.js](tgdirect.js), и
значит виден любому, кто открыл исходный код сайта. Так и сделано изначально:
без сервера иначе не отправить заявку. Отсюда правила:

- заведите **отдельного** бота только для заявок с сайта, не личного;
- не давайте ему права администратора в каналах и группах;
- если бот начнёт вести себя странно — `/revoke` у @BotFather и новый токен
  в `tgdirect.js` (первая строка настроек).

Заявки приходят всё равно только на `CHAT_ID` — их не потерять.

## Telegram-канал

Ссылка на канал с работами задаётся один раз в [site.config.js](site.config.js)
(`channelUrl`) и подставляется в шапку, подвал и кнопки. Там же `botUsername` —
для запасной ссылки на бота.

## Примеры эскизов

Раздел «Примеры» на главной — витрина эскизов: готовых рисунков, которые
берутся за основу наклейки. Цен у эскизов нет — стоимость считается только
по плёнке, размеру и тиражу в калькуляторе.

Клиент выбирает эскиз карточкой в разделе «Примеры» или селектом «Эскиз»
в форме заявки; выбранное название уходит модератору отдельной строкой. Эскиз — часть наклейки:
у каждой позиции корзины свой.

Чтобы добавить или заменить эскиз:

1. Положите картинку в `sketches/img/` (лучше `.jpg`, до ~300 КБ).
2. Добавьте или поправьте блок в [sketches/catalog.js](sketches/catalog.js):

```js
{ id: "moy-eskiz", title: "Название эскиза", img: "sketches/img/moy-eskiz.jpg" }
```

Эскизы — статичный список, админ-панелью не управляются. Если каталог пуст,
раздел «Примеры» на странице скрыт.

## Шаблоны и как их публиковать

Витрина шаблонов на сайте читает каталог [templates/catalog.js](templates/catalog.js).
Пока каталог пуст, блок «Готовые шаблоны» на странице просто скрыт — пустых
каркасов не остаётся.

Чтобы добавить шаблон:

1. Откройте `admin.html`, задайте пароль.
2. **Галерея шаблонов** → выберите фото, впишите название, материал, размер и
   тираж. Цена на карточке считается сама.
3. **Опубликовать в GitHub** — если заполнены токен GitHub, владелец, репозиторий
   и ветка. Либо **Скачать архив для GitHub** и загрузите файлы руками.

Клик по карточке на сайте подставляет материал, размер и тираж в расчёт —
остаётся подтвердить наклейку, добавить её в корзину и отправить заявку.

## Файлы

| Файл | Что делает |
| --- | --- |
| `index.html` | главная: плёнка, шаблоны, калькулятор, корзина и форма заявки |
| `pricing.js` | ставки, минимум заказа, скидки, расчёт корзины, проверка заявки, текст для Telegram, строки для таблицы |
| `cart.js` | корзина: позиции, тираж, итог, хранение в браузере |
| `site.config.js` | бот, канал и подписи сайта |
| `site.js` | калькулятор; модуль отправки подгружается только при отправке формы |
| `gallery-loader.js` | подключает галерею только при непустом каталоге |
| `gallery.js` | витрина шаблонов; загружается по необходимости |
| `sketches/catalog.js` | список примеров эскизов (картинка + название) |
| `sketch-gallery.js` | витрина эскизов и выбор в форме заявки |
| `tgdirect.js` | отправка заявки в Telegram и Google-таблицу (здесь же токен, chat_id и `SHEET_URL`), загружается при отправке |
| `google-apps-script/Code.gs` | код для Google Apps Script: принимает заявку и дописывает строки в таблицу |
| `orderlink.js` | запасная ссылка на бота для заявки из одной позиции, загружается только при ошибке отправки |
| `templates.js` | модель шаблона, архив ZIP, чтение и запись каталога; загружается вместе с галереей |
| `templatesync.js` | публикация каталога и фото через GitHub API |
| `templates/catalog.js` | сам каталог (`globalThis.SITE_TEMPLATES`) |
| `admin.html`, `adminlock.js` | меню админа: настройки и галерея |
| `bot.html`, `botcore.js`, `botpanel.js` | внутренняя панель бота |

## Дизайн

Тёмная тема, неоновые подсветки, объёмная 3D-сцена и hover-отклики сохранены.
Для плавной прокрутки убраны бесконечные анимации, следование свечения за
курсором и размытие фона под большими/липкими панелями. Дальние секции браузер
подготавливает по мере прокрутки. Необязательные модули заявки загружаются при
отправке формы, код галереи — только если в каталоге появились шаблоны.

## Запуск

```bash
npm start
```

Откройте адрес, который выведет команда (по умолчанию `http://localhost:8080`).
Для расчёта и отправки заявки нужен включённый JavaScript.

## Проверки

```bash
npm test
```

Проверяются ставки и минимум заказа, совпадение суммы на сайте и в заявке,
корзина (несколько наклеек, минимум на всю корзину, хранение), отправка в Telegram
и в таблицу на заглушках (в том числе отказ одного из каналов), работа скрипта
таблицы, отказы при ошибках сети и токена, галерея
шаблонов и отсутствие токена в публичных файлах.
