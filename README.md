# Плёнка ORACAL — информация и калькулятор

Главная страница (`index.html`) рассказывает о видах самоклеящейся виниловой плёнки и считает ориентировочную стоимость по площади. На странице нет галереи примеров, формы заявки или оформления заказа.

## Расчёт цены

Формула: **ширина (см) × высота (см) × ставка выбранной плёнки × количество**.

| Вид плёнки | Цена за см² |
| --- | ---: |
| Матовая | 3 ₽ |
| Глянцевая | 5,5 ₽ |
| Прозрачная | 6 ₽ |
| Металлик | 7 ₽ |
| Светоотражающая | 8 ₽ |

Базовая ставка матовой плёнки изменена с 5 ₽ на 3 ₽ за см². Калькулятор считает только стоимость материала — без минимальной суммы и скидок за тираж.

## Запуск

Сайт статический, сборка и зависимости не нужны. Для локального просмотра:

```bash
npm start
```

Откройте адрес, который выведет команда (по умолчанию `http://localhost:8080`). Для расчёта в браузере должен быть включён JavaScript.

## Файлы

- `index.html` — адаптивная информационная страница: виды плёнки, характеристики и калькулятор.
- `site.js` — интерактивная часть калькулятора и обновление ставок на странице.
- `pricing.js` — единая таблица ставок и функция расчёта.
- `templates/catalog.js` — пустой каталог; примеры удалены и главная страница не загружает галерею.
