    Что нужно знать

    • Пока вкладка открыта — заявки приходят за секунды. Закрыли вкладку — Telegram хранит недоставленные команды до 24 часов, и они придут, когда откроете панель снова.
    • Не запускайте одновременно два приёмника: эту панель, GitHub Actions и node bot.js — Telegram отдаёт обновления только одному, второй получит ошибку 409.
    • В ссылке заявки Telegram разрешает 64 символа, поэтому комментарий клиент дописывает боту сообщением — панель перешлёт его модератору.
