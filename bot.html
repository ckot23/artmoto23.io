Панель бота

Здесь бот принимает заявки без хостинга и без установки программ: пока эта вкладка открыта, страница сама забирает заявки у Telegram и пересылает их модератору.

Токен останется только в этом браузере. Он хранится в localStorage вашего устройства и никогда не попадает в файлы сайта: всё, что лежит в репозитории, видят посетители. Не открывайте эту страницу на чужом компьютере и не отправляйте токен в переписке.

Свой chat_id можно узнать, написав боту /id (или @userinfobot).

Журнал

Пока ничего не происходило.

Что нужно знать

  • Пока вкладка открыта — заявки приходят за секунды. Закрыли вкладку — Telegram хранит недоставленные команды до 24 часов, и они придут, когда снова откроете эту страницу (или когда запустится GitHub Actions, если он включён).
  • Вкладка должна оставаться открытой. На телефоне удобно закрепить её или открыть страницу как мини-приложение Telegram: @BotFather → Bot Settings → Menu Button.
  • Не запускайте одновременно два приёмника: эту панель, GitHub Actions и node bot.js — Telegram отдаёт обновления только одному, второй получит ошибку 409.
  • Ограничение Telegram: в ссылке заявки помещается 64 символа, поэтому комментарий клиент дописывает боту сообщением — панель перешлёт его модератору.
